Test your memory by repeating the sequence of colors & sounds. Each level gets harder!

## 🎮 About the Game  
The *Simon Memory Game* is a fun and interactive game where the player must repeat a sequence of lights and sounds. With each correct round, the sequence grows, testing your memory and focus.  

---

## 🚀 Features  
✅ Interactive gameplay with smooth animations  
✅ Sounds for each color button  
✅ Responsive design (works on desktop & mobile)  
✅ Increasing difficulty with each level  
✅ Restart option on game over  

---

## 🕹 How to Play  
1. Press any *key* to start the game.  
2. Watch as the game flashes a *sequence of colors*.  
3. Repeat the sequence by clicking on the correct buttons.  
4. Each round adds *one more color* to the sequence.  
5. If you choose the wrong color → *Game Over*!
